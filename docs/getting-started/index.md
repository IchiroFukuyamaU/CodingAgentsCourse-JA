# コーディングエージェント入門

**UiPath CLI とスキルをセットアップし、CLI の感触をつかんだうえで、最初のエージェントの構築と公開までをコーディングエージェントから行います。**

## 概要

**コーディングエージェント** は、やり方さえ分かれば、開発者と同じように UiPath の自動化を構築・運用できます。そのために教え込むものは 2 つです。

- **UiPath CLI** — エージェントがプラットフォームとやり取りするためのコマンドラインインターフェイス
- **UiPath スキル** — その CLI を *いつ*・*どのように* 使うのかをエージェントに伝える、キュレーション済みの手順パック

この最初の演習は準備運動にあたります。環境を整え、CLI とスキルでできること・使い方の感触をつかんだうえで、小さなエージェントで **構築と公開のループを 1 周** 通して体験します。コーディングエージェントにエージェントの内容を説明し、スキャフォールドされる様子を見守り、Studio Web に公開して実行する、という流れです。ここで作るエージェントはあえてシンプルにしてあります。狙いは、以降の（より本格的な）演習で何度も使うことになるワークフローを身につけることだからです。

!!! info "はじめる前に: 前提条件"
    以下はセッション開始 **前** に準備しておいてください。事前準備が必要なのはコーディングエージェントだけです。

    - **コーディングエージェントのインストールとサインイン** — 現時点でスキルが提供されているのは、Claude Code、Cursor、GitHub Copilot、Gemini CLI、Codex、OpenCode です。いずれかを選んでインストールし、事前にログインしておいてください。それ以外はエージェントがその場でセットアップを手伝ってくれます。LLM を利用するための有効なサブスクリプション、または API キーも必要です。
    - **ソフトウェアをインストールできるノート PC**（インストーラーの実行には通常、管理者権限が必要です）。
    - **UiPath Cloud アカウント**。本ワークショップでは `{{ training_url }}/{{ training_tenant }}` を使用します。招待が届いていない場合はトレーナーにご相談ください。
    - **Node.js / npm** — UiPath CLI に必要です。未インストールの場合は、コーディングエージェントに導入してもらえます。
    - **安定したインターネット接続**。社内規定で必要な場合は **VPN** も。

    UiPath CLI とスキルは最初のレッスンでインストールします。事前に入れておく必要はありません。
